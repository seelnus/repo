# 360 环评员工列表页移动端重设计实施计划

1. 扩展 `GET /api/eval/tasks` 的批次返回值，增加 `cycleEndAt`，并补充员工范围、已发布状态和截止时间字段单元测试。
2. 新增填写端列表视图模型模块，负责 JWT 展示姓名解析、任务扁平化、待办/已完成拆分、截止时间排序、紧急状态、进度和结果完成度计算。
3. 将 `/eval-fill` 登录后区域拆成身份头部、任务概览、待办卡片、已完成折叠区和归档结果卡片，保留现有登录、401、答题和结果详情导航逻辑。
4. 使用 Ant Design `Dropdown`、`Tabs`、`Badge`、`Progress`、`Card`、`Tag`、`Button`、`Collapse`、`Skeleton`、`Empty` 和 `Result` 实现已确认的方案 A。
5. 增加 `max-width: 768px` 的移动端样式，包括粘性头部、单列任务卡片、44px 触控区、长文本换行和安全区域留白；桌面端保持 720px 居中布局。
6. 验证无截止时间、已截止、全部完成、无任务、无归档结果、结果不可用、接口失败和 401 等边界状态。
7. 执行后端完整测试、前后端生产构建、差异检查，并用本地已有员工身份实际访问两个页签。
8. 仅提交本次设计计划与代码文件，不包含工作区原有未提交改动；用户验收后再单独推送和发布。
