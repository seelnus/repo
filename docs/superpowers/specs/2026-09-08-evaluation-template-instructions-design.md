# 360 环评模板填写说明设计

## 背景

360 环评模板目前可以配置模板名称、维度、评分题和填空题，但缺少一处面向整份问卷的统一说明。管理员需要在员工开始评价前说明填写规范、评价口径、填写目的和注意事项。

本次改动仅服务于新版 360 环评模板，不扩展普通问卷考核、案例收集和宣传文档。

## 目标

- 管理员可以在 360 环评模板上维护一段多行填写说明。
- 员工打开自评、他评或历史兼容的领导评价任务时，在题目之前阅读统一说明。
- 填写说明跟随模板保存，并在批次发布时固化，避免已发布批次受模板后续修改影响。
- 旧模板和未填写说明的模板保持现有页面效果。

## 非目标

- 不支持富文本、图片、附件或可点击链接。
- 不把填写说明作为题目处理。
- 不把填写说明纳入题号、答题进度、评分、统计或 Excel 导出。
- 不为普通问卷考核、案例收集或宣传文档增加该字段。
- 不允许已发布批次直接修改填写说明。

## 交互设计

### 管理端

在 360 环评的统一模板编辑区中，将“填写说明（选填）”放在模板名称下方、维度和题目编辑区域上方。

使用多行文本框：

- 占满模板内容区宽度。
- 默认显示约 4 行。
- 占位提示为“请输入本次环评的填写规范、评价口径或注意事项”。
- 显示实时字数统计。
- 最多输入 2000 个字符。
- 模板只读时，说明与模板其他字段一样只读展示。

填写说明属于模板级信息，不支持拖拽，不随题目排序变化。

### 员工填写端

当批次快照中的填写说明去除首尾空白后仍有内容时，在任务标题和被评人信息下方、题目列表上方显示独立说明卡片。

说明卡片包含：

- 标题“填写说明”。
- 管理员填写的正文。
- 按原始换行展示正文。

说明卡片不显示编号，不计入题目数量和答题进度。说明为空时不渲染卡片，也不保留空白间距。

自评、他评和系统中保留的领导评价任务使用同一份批次快照说明。

## 数据设计

扩展现有 360 模板 JSON 结构：

```ts
type EvalTemplate = {
  version: 2;
  kind: 'evaluation';
  instructions?: string;
  dimensions: EvalDimension[];
  questions: EvalQuestion[];
};
```

`instructions` 保存为普通字符串，最大长度为 2000 个字符。

该字段存入现有 `Survey.schemaJson`，不新增数据库列，因此不需要数据库迁移。旧模板没有该字段时，规范化逻辑将其视为空字符串。

## 数据流

1. 新建模板时，前端默认生成 `instructions: ''`。
2. 管理员编辑说明并保存模板。
3. 前端将说明与维度、题目一起写入模板 `schemaJson`。
4. 后端规范化说明，去除首尾空白并校验最大长度。
5. 环评批次发布时，完整模板写入 `EvalCycle.templateSnapshotJson`，其中包含填写说明。
6. 员工打开评价任务时，后端继续优先返回批次模板快照。
7. 填写页从任务的 `survey.schemaJson.instructions` 读取并展示说明。

批次发布后，即使管理员修改原模板，已发布批次仍使用发布时固化的说明。未来发布的新批次使用模板的最新说明。

## 校验与错误处理

- 前端文本框通过 `maxLength=2000` 限制输入，并显示字数统计。
- 后端必须独立校验长度，不能只依赖前端。
- 后端收到非字符串值时按空字符串处理。
- 保存前统一去除首尾空白，正文内部换行和空格保留。
- 超过 2000 个字符时，后端拒绝保存并返回明确错误：“填写说明不能超过 2000 字”。
- 员工端使用普通文本节点展示，并通过样式保留换行，不使用 `dangerouslySetInnerHTML`。

## 兼容性

- 旧版 360 模板缺少 `instructions` 时自动得到空字符串。
- 未填写说明的模板与现有管理端、填写端行为一致。
- 已发布批次已经保存模板快照；新增字段不会改变旧快照内容。
- 本次不修改模板版本号，仍使用 `version: 2`，因为新增字段是可选且向后兼容的。
- 评分、提交、答题校验、关系生成、统计报告和 Excel 导出不读取该字段。

## 测试方案

### 后端

- 规范化旧模板时，缺少 `instructions` 不报错且结果为空字符串。
- 保存包含多行说明的模板后，读取结果保留正文内部换行。
- 保存仅包含首尾空白的说明后，结果为空字符串。
- 超过 2000 个字符时拒绝保存并返回明确错误。
- 发布批次后，模板快照包含发布当时的说明。
- 批次发布后修改原模板，不改变已发布批次快照。

### 管理端

- 新建和编辑 360 模板时显示填写说明输入框。
- 输入框显示字数统计并限制 2000 个字符。
- 保存后重新打开模板，说明内容正确回填。
- 非草稿批次的模板界面保持只读。

### 员工填写端

- 有说明时，在题目之前显示说明卡片。
- 无说明时，不显示说明卡片或多余空白。
- 多行内容按原始换行显示。
- 自评、他评和领导评价任务展示相同说明。
- 说明不影响题号、题目总数和填写进度。
- 正常提交评价后，答案和统计结果不包含说明内容。

### 回归

- 旧模板可以继续编辑、绑定和发布。
- 评分题、填空题、案例说明与必填校验保持正常。
- 环评结果计算和各工作表导出结果保持不变。

## 验收标准

1. 只有 360 环评模板出现“填写说明（选填）”。
2. 说明跟随模板保存，支持换行且不超过 2000 个字符。
3. 员工填写时，说明固定显示在标题/被评人信息与题目之间。
4. 说明不计题号、不计进度、不参与提交数据和统计导出。
5. 已发布批次使用发布时快照，模板后续修改不会改变其说明。
6. 旧模板和空说明模板的现有行为不受影响。
