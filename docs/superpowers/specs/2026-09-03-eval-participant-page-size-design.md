# 参评人员分页条数修复设计

## 背景

参评人员表格将 Ant Design 分页的 `pageSize` 固定为 15。每页条数选择器虽然可见，但用户选择新条数后，组件会在下次渲染时再次收到固定值 15，导致设置看起来没有生效。

## 方案

- 将固定的 `pageSize: 15` 改为只负责初始值的 `defaultPageSize: 15`。
- 由 Ant Design Table 内部管理当前页码和每页条数，避免外部固定值覆盖用户选择。
- 显式开启每页条数选择器，提供 10、15、20、50、100 条选项。

## 范围

只修复参评人员表格的本地前端分页。不修改后端接口、数据源、人员勾选和保存逻辑，不处理项目中其他表格的分页。

## 验收

1. 表格初始每页显示 15 条。
2. 选择其他每页条数后，当前页立即按新数量显示。
3. 切换每页条数时回到第 1 页。
4. 普通翻页正常，已勾选的参评人员不受影响。
5. 前端构建通过。
