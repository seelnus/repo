# 新版移除“领导评价”新增入口设计

**日期**：2026-08-31

**状态**：方案 A 已确认，待代码实施

## 1. 目标

新版 360 环评使用统一题目模板，计分只区分“自评”和“非自评”。因此，新版人工添加关系时不再提供“领导评价”类型，减少无实际计算差异的选项。

## 2. 界面调整

- 新版“人工添加评价关系”的关系类型只保留“自评、他评”。
- 新版默认关系类型由“领导评价”改为“他评”。
- 新版入口按钮由“人工添加关系（领导/异常补配）”改为“人工添加关系（异常补配）”。
- 旧版人工添加关系仍保留“自评、他评、领导评价”，默认仍为“领导评价”。

## 3. 兼容边界

- 不删除或迁移数据库中的 `leader` 关系。
- 不修改后端允许的关系类型及接口校验。
- 不修改计分、填写任务、统计或导出逻辑。
- 新版已有的历史 `leader` 关系继续在关系明细、报告和导出中显示为“领导评价”。

## 4. 实现方式

复用 `RelationsTab` 现有的 `cycleId.version`：

- `version >= 2` 时使用新版按钮文案、默认值和两项下拉选项。
- `version < 2` 或没有版本号时保持旧版行为。

不新增接口、不新增字段，不进行无关重构。

## 5. 验收标准

1. 新版弹窗只能选择“自评、他评”，默认显示“他评”。
2. 新版按钮显示“人工添加关系（异常补配）”。
3. 新版历史 `leader` 明细仍显示“领导评价”。
4. 旧版仍可选择并新增“领导评价”。
5. 前端生产构建通过。
