# 360 环评填空题设计

## 1. 背景与目标

当前新版 360 环评模板仅支持 `evaluation_score` 评分题。评分题通过 0–5 分行为选项收集量化评价，并按照所有有效答卷等权平均计算题目分、维度分和员工最终分。

本次增加独立的环评填空题，用于收集不适合量化的文字反馈。填空题不参与任何评分，同时支持管理员配置必填或选填。

## 2. 已确认规则

- 新题型使用独立类型 `evaluation_text`。
- 填空题统一使用多行文本框，不区分单行和多行类型。
- 填空题只收集文字反馈，不参与题目分、维度分或员工最终分。
- 每道填空题支持设置必填或选填。
- 填空题可以关联所属维度，用于模板组织和报告分组。
- 文字反馈在个人报告和导出中展示。
- 反馈仅保留评价关系标签，包括自评、同事和领导，不展示评价人姓名。
- 单条反馈最多 2000 个字符。

## 3. 模板结构

### 3.1 题型联合结构

环评模板继续使用统一模板，题目数组允许两种题型：

```ts
type EvalQuestion = EvalScoreQuestion | EvalTextQuestion;

type EvalScoreQuestion = {
  id: string;
  type: "evaluation_score";
  label: string;
  description?: string;
  dimensionId: string;
  required: boolean;
  countInScore: boolean;
  options: Array<{ score: number; label: string }>;
  casePrompt?: string;
  caseRequiredScores: number[];
};

type EvalTextQuestion = {
  id: string;
  type: "evaluation_text";
  label: string;
  description?: string;
  dimensionId: string;
  required: boolean;
  maxLength: 2000;
};
```

`evaluation_text` 不提供 `countInScore`、评分选项、案例提示语或案例必填分值。后端无条件排除填空题，不依赖前端配置来决定是否计分。

### 3.2 模板编辑

题目模板页提供两个明确入口：

- 添加评分题
- 添加填空题

填空题编辑卡包含：

- 题型标识“填空题”。
- 题目标题。
- 补充说明。
- 所属维度。
- 必填/选填开关。
- 删除题目操作。

模板仍只允许在草稿批次中选择和编辑。批次发布后使用模板快照；已发布、已截止、已锁定和已归档批次不能修改题型或题目配置。

## 4. 员工作答

### 4.1 展示

填空题显示题目标题、补充说明和多行文本框。必填题显示必填标识，输入区域显示最多 2000 字的计数提示。

### 4.2 答案格式

填空题答案按题目 ID 保存在现有答卷 JSON 中：

```json
{
  "text-question-1": "希望继续加强跨部门沟通。"
}
```

本次不增加答卷数据库字段，也不改变现有评分题答案格式。

### 4.3 提交校验

- 必填题缺失、空字符串或仅包含空格和换行时拒绝提交。
- 选填题的空白内容按未作答处理。
- 非字符串答案拒绝提交。
- 超过 2000 个字符时拒绝提交。
- 前端提供即时提示，后端依据发布时的模板快照再次执行相同校验。
- 后端只接受模板快照中存在的题目 ID，防止提交无效或伪造题目。
- 反馈内容只按纯文本展示，不执行其中的 HTML 或脚本。

## 5. 计分规则

现有计分公式保持不变，但参与计算的题目集合明确限定为 `evaluation_score` 且 `countInScore = true` 的题目。

```text
QuestionScore(e, q) = 该员工该评分题所有有效答卷分值的等权平均
EmployeeScore(e) = 该员工所有有效评分题 QuestionScore 的等权平均
```

填空题：

- 不生成题目分。
- 不进入维度平均值分母。
- 不进入员工最终分分母。
- 不影响自评、他评或综合评分。

如果模板只包含填空题，答卷仍可正常提交，员工总分和维度分显示“暂无评分”，不能显示为 0 分。

## 6. 报告与导出

### 6.1 个人报告

个人报告新增“文字反馈”区域，按照“所属维度 → 填空题”分组。每条非空反馈显示：

- 评价关系：自评、同事或领导。
- 反馈正文。

不展示评价人的姓名、账号或其他可识别身份的信息。空白的选填答案不生成反馈记录。

### 6.2 Excel 导出

原始答卷工作表为每道填空题增加独立列。

新增“文字反馈”工作表，字段为：

- 被评人
- 部门
- 评价关系
- 维度
- 题目
- 反馈内容

“文字反馈”工作表不包含评价人姓名。现有员工汇总、逐题评分和案例说明工作表继续只处理对应的评分数据。

## 7. 兼容性

- 旧版 `version = 1` 批次继续走原有兼容页面和数据逻辑。
- 已有新版模板只有 `evaluation_score` 时，保存、发布、作答、计分和导出行为保持不变。
- 本次使用现有 JSON 模板和答案字段，不需要新增数据库表或列。
- 新代码读取缺少填空题字段的历史模板时采用原有评分题默认规则。
- 发布后的模板快照保证后续模板修改不会改变执行中或历史答卷的校验和展示规则。

## 8. 异常处理

| 场景 | 处理规则 |
| --- | --- |
| 必填填空题为空或仅含空白 | 前后端拒绝提交并定位题目 |
| 反馈超过 2000 字 | 前后端拒绝提交并提示长度限制 |
| 填空题答案不是字符串 | 后端拒绝提交 |
| 答案包含模板外题目 ID | 后端拒绝提交 |
| 纯填空模板完成作答 | 正常提交，评分显示“暂无评分” |
| 选填题未填写 | 正常提交，不生成反馈记录 |
| 反馈包含 HTML 或脚本 | 作为普通文本显示 |

## 9. 测试范围

### 9.1 后端单元测试

- 模板规范化保留评分题和填空题的联合结构。
- 必填、选填、纯空白、非字符串、2000 字和超长答案校验。
- 混合题型答卷只统计评分题。
- 填空题不进入题目分、维度分和最终分。
- 纯填空模板返回空评分而不是 0 分。

### 9.2 接口与流程测试

- 创建、编辑并绑定包含填空题的统一模板。
- 发布后使用模板快照作答。
- 已发布批次不能修改题型配置。
- 个人报告按维度和题目展示匿名文字反馈。
- 原始答卷和文字反馈工作表导出正确。

### 9.3 回归测试

- 现有 0–5 分评分与案例必填规则保持有效。
- 所有答卷等权平均规则不变。
- 只有评分题的新版批次行为不变。
- 旧版批次兼容行为不变。

## 10. 验收标准

1. 管理员可以在统一环评模板中新增填空题，并设置必填或选填。
2. 员工可以通过多行文本框填写不超过 2000 字的反馈。
3. 必填、选填及长度规则在前后端表现一致。
4. 填空题不会改变任一员工的题目分、维度分和最终分。
5. 个人报告能够按维度和题目展示匿名关系标签及文字反馈。
6. 导出包含原始填空答案和独立的匿名文字反馈明细。
7. 既有新版评分模板和旧版批次能够继续正常使用。
